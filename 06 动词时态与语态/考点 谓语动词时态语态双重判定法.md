# 考点：谓语动词时态语态双重判定法

```
谓语动词两步判定流程
  │
  ├─ 步骤 1：判定语态（主动还是被动）
  │    检查主语与动词的关系：
  │    ├─ 主动 ──> 采用主动时态形式
  │    └─ 被动 ──> 结构中必须包含 be + 过去分词
  │
  └─ 步骤 2：判定时态（坐标定位）
       ├─ 查看是否有明确的时间状语（since, recently, by then 等）
       ├─ 查看上下文语境的基准时间（记叙文多用一般过去时）
       └─ 根据动作发生的前后时序确定具体时态
```
