# 考点：非谓语动词解题四步判定算法

```
[第一步：判谓语]
句子是否有独立谓语且无连词？
  └─ 是 ──> 该空必定填【非谓语动词】

[第二步：找逻辑主语]
  ├─ 作状语 ──> 找主句主语（逗号后的主语）
  ├─ 作定语 ──> 找被修饰的名词
  └─ 作宾补 ──> 找前面的宾语

[第三步：判主被动]
  ├─ 逻辑主语发出动作 ──> 主动 (doing / to do)
  └─ 逻辑主语承受动作 ──> 被动 (done / to be done)

[第四步：判时态与目的]
  ├─ 动作将发生或表目的 ──> to do
  ├─ 动作与谓语同时进行 ──> doing
  └─ 动作先于谓语完成 ──> having done / done
```
