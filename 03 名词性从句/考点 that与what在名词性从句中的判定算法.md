# 考点：that 与 what 在名词性从句中的判定算法

```
名词性从句引导词判定流程
  │
  ├─ 检查从句内部主干成分
  │    ├─ 从句成分完整（主语、谓语、宾语/表语齐全）
  │    │    ├─ 陈述一件确定的事实 ──> 填 that
  │    │    └─ 表达“是否”的不确定性 ──> 填 whether
  │    │
  │    └─ 从句缺少主语、宾语或表语
  │         └─ 表达“所……的事物/话语/内容” ──> 填 what
```

- 例 1：`____ we need to do is keep calm.` $	o$ do 缺少宾语，填 **What**。
- 例 2：`____ we will succeed is beyond doubt.` $	o$ 从句主谓完整，陈述事实，填 **That**。
