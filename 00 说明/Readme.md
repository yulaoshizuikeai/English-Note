# 项目说明与导航

## 项目定位

本项目为高中英语语法体系知识库，基于外研版高中英语教材（必修 1~3 册、选择性必修 1~4 册）的 **Using language** 板块与高考评价体系构建。

## 章节结构

1. **01 简单句结构与句子成分**：简单句 7 大基本句型与句子成分划分。
2. **02 定语从句**：限制性与非限制性定从、关系代词与副词、介词提前。
3. **03 名词性从句**：主语从句、表语从句、宾语从句与同位语从句。
4. **04 状语从句**：时间、条件、让步、结果状语从句及状从省略。
5. **05 非谓语动词**：不定式、现在分词、过去分词、with 复合结构与四步解题法。
6. **06 动词时态与语态**：核心 8 大时态、进阶完成进行时、复杂被动语态。
7. **07 情态动词与虚拟语气**：情态推测、完成式、条件句与名词性从句虚拟。
8. **08 特殊句式**：it 形式主宾语、倒装、强调、省略。
9. **09 主谓一致**：语法一致、意义一致、就近原则与就远原则。
10. **10 高考题型与语法运用**：语法填空流程、读后续写句式升级、应用文句型。
11. **11 外研版高中英语教材知识清单**：全七册 42 个单元 Using language 完整清单。
