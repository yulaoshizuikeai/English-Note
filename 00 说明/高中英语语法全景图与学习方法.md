# 高中英语语法全景图与学习方法

## 一、语法知识全景架构

```
英语语法体系
├─ 句子骨架
│   ├─ 词性（名词、动词、形容词、副词、代词、介词、连词）
│   └─ 7 种简单句基本结构（主谓、主谓宾、主系表、主谓双宾、主谓宾补、主谓状、主谓宾状）
├─ 复合句体系（三大从句）
│   ├─ 定语从句（相当于形容词修饰名词）
│   ├─ 名词性从句（主从、宾从、表从、同位语从句，相当于名词作成分）
│   └─ 状语从句（时间、地点、原因、条件、让步、目的、结果、方式、比较）
├─ 动词系统（语法核心）
│   ├─ 谓语动词：时态（8大高考核心时态）+ 语态（主动/被动）+ 主谓一致
│   └─ 非谓语动词：不定式（to do）+ 现在分词/动名词（-ing）+ 过去分词（-ed）
└─ 特殊句式
    ├─ 形式主语与形式宾语 it
    ├─ 倒装（部分倒装与完全倒装）
    ├─ 强调句型
    ├─ 省略与虚拟语气
```

## 二、学习与做题方法

1. **找准句子主干**：任何长难句的第一步永远是找出核心主语和唯一的谓语动词。
2. **区分谓语与非谓语**：在语法填空题中，遇到动词先看句子是否缺少谓语。
3. **从句分析看内部成分**：定语从句看先行词在从句中作什么成分；名词性从句看从句内部是否缺主语或宾语。
