# 句子核心成分与长难句分析

长难句的本质是在 7 种简单句基本句型的基础上，叠加修饰成分（定语、状语、同位语、插入语）与从句。

---

## 一、核心成分与附属成分划分

```
句子成分
├─ 核心主干
│   ├─ 主语 (Subject)：动作发出者或陈述对象
│   ├─ 谓语 (Predicate)：动作或状态（必须有时态、语态和人称变化）
│   ├─ 宾语 (Object)：动作承受者
│   └─ 表语 (Predicative)：系动词后的陈述成分
└─ 修饰成分（枝叶）
    ├─ 定语 (Attributive)：修饰名词或代词
    ├─ 状语 (Adverbial)：修饰动词、形容词、副词或整个句子
    ├─ 补语 (Complement)：补充说明主语或宾语
    └─ 同位语 (Appositive)：对前面的名词进行同等地位的补充解释
```

---

## 二、长难句切分三步法

1. **圈出谓语动词**：找到句子中的全部动词，区分哪些是谓语动词，哪些是非谓语动词。
2. **标出连接词**：圈出 and, but, which, that, because, when 等连词，确定主句与从句的边界。
3. **去枝叶抓主干**：括号括起介词短语、定语从句和非谓语修饰语，裸露出主干的主谓宾结构。
