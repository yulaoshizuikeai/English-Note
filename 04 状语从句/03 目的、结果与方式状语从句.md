# 目的、结果与方式状语从句

---

## 一、目的状语从句

- 引导词：`so that, in order that, for fear that, in case`
- 从句谓语常带有 `can, could, may, might, should` 等情态动词：
  - *He spoke clearly so that everyone could hear him.*

---

## 二、结果状语从句：so... that... 与 such... that...

| 句型 | 后接词性结构 |
| :--- | :--- |
| **so + adj. / adv. + that...** | *The box is so heavy that I can't lift it.* |
| **so + adj. + a/an + 可数单数 + that...** | *He is so kind a boy that we all like him.* |
| **so + many / few / much / little + 名词 + that...** | *There are so many people that the hall is full.* |
| **such + a/an + adj. + 可数单数 + that...** | *He is such a kind boy that we all like him.* |
| **such + adj. + 可数复数 / 不可数名词 + that...** | *It was such bad weather that we stayed home.* |
