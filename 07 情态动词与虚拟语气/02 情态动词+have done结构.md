# 情态动词 + have done 结构

表示对**过去发生事情**的推测、责备或遗憾：

| 结构 | 含义 | 语境说明 |
| :--- | :--- | :--- |
| **must have done** | 过去一定做了…… | 对过去事实的肯定推测 |
| **can't / couldn't have done** | 过去不可能做过…… | 对过去事实的否定推测 |
| **should have done** | 本应该做某事（却没做） | 表达责备或遗憾 |
| **shouldn't have done** | 本不该做某事（却做了） | 表达责备或后悔 |
| **could have done** | 本本来可以做到……（却没做） | 表达未实现的可能 |
| **needn't have done** | 本没有必要做……（却做了） | 做了多余的事 |
