# 虚拟语气在条件句中的时态倒退规则

---

## 一、if 条件句时态倒退对照表

| 时间类型 | If 从句谓语动词 | 主句谓语动词 |
| :--- | :--- | :--- |
| **与现在事实相反** | 过去式（be 动词一律用 were） | `would / could / should / might + do` |
| **与过去事实相反** | `had + done` | `would / could / should / might + have done` |
| **与将来事实相反** | 1. 过去式<br>2. `should + do`<br>3. `were to + do` | `would / could / should / might + do` |

---

## 二、错综时间条件句与条件句省略

1. **错综时间条件句**：从句动作与主句动作发生在不同时间，分别按照各自的时间设定时态：
   - *If I had worked hard before, I would be successful now.*（从句与过去相反，主句与现在相反）
2. **if 的省略与倒装**：当从句含有 `had, were, should` 时，可以省略 if，并将 had, were, should 提前到句首：
   - *Had you taken my advice, you wouldn't have failed.* (= If you had taken...)
   - *Were I in your position, I would accept the offer.* (= If I were...)
