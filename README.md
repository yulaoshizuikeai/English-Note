# 高考英语语法知识库 (Yulaoshizuikeai's English Note)

基于外研版（2019版）与人教版高中英语教材的高考英语语法知识库与复习指南。

## 本地开发与构建

```bash
# 安装依赖
pnpm install

# 启动本地开发服务
pnpm docs:dev

# 构建静态文档站点
pnpm docs:build

# 本地预览构建产物
pnpm docs:preview
```

## 目录结构

- `00 说明`：项目说明、反馈渠道与语法学习方法
- `01 简单句结构与句子成分`：7 大基本句型与长难句分析
- `02 定语从句`：关系代词、关系副词、介词+关系代词、非限制性定从
- `03 名词性从句`：主从、表从、宾从、同位语从句与 that/what 判定
- `04 状语从句`：时间/条件/让步/结果状语从句与从句省略
- `05 非谓语动词`：不定式、现在分词、过去分词与 with 复合结构
- `06 动词时态与语态`：高考核心 8 大时态、复杂被动语态与时态坐标
- `07 情态动词与虚拟语气`：情态推测、完成式与条件句虚拟
- `08 特殊句式`：形式主宾语 it、倒装、强调与省略
- `09 主谓一致`：语法/意义一致、就远原则与就近原则
- `10 高考题型与语法运用`：语法填空、读后续写句式升级、应用文模板
- `11 外研版高中英语教材知识清单`：全七册 42 单元 Using language 完整清单
